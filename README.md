 NAS | Network Administration & Security
منصة تعليمية متخصصة في إدارة وأمن الشبكات
NAS هو مشروع تعليمي يهدف إلى مساعدة الطلاب والمهتمين بمجال الشبكات والأمن السيبراني على تطوير معارفهم ومهاراتهم من خلال الاختبارات التفاعلية والمحتوى التقني.

🎯 أهداف المشروع
تبسيط مفاهيم الشبكات وأمن المعلومات.
توفير اختبارات تعليمية تفاعلية.
تطوير المهارات التقنية للطلاب.
الجمع بين المصطلحات العربية والإنجليزية.
توفير تجربة تعلم سهلة ومنظمة.

⚙️ التشغيل والتثبيت
استنساخ المشروع:
git clone https://github.com/Badrouxp/cyber-quiz-bot.git
الدخول إلى مجلد المشروع:
cd cyber-quiz-bot
تثبيت المكتبات:
pip install -r requirements.txt
إعداد متغيرات البيئة في ملف .env حسب إعدادات المشروع.
تشغيل البوت:
python bot.py
